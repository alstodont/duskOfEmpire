# Update

## Определение

> [!abstract] Определение
> За один вызов читает контекст шага и меняет состояние мира. Кадр не рисует.

^glossary-def

**Тип записи:** метод
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[Update#Определение|Update]] — единственный метод [[ISimSystem#Определение|ISimSystem]]. В Phase 0 этим методом куб принимает WASD и поворот за мышью. Поля контекста шага источники не задают.

## Принимаемые типы данных

| Параметр | Тип | Описание |
| --- | --- | --- |
| `ctx` | контекст шага | Состояние, которое шаг имеет право читать и менять. Состав полей источники не задают |
| **Возвращает** | нет | Метод значение не возвращает |
