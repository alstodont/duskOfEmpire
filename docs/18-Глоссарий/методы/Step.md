# Step

## Определение

> [!abstract] Определение
> Продвигает симуляцию хоста ровно на один фиксированный шаг длительностью 1/30 секунды.

^glossary-def

**Тип записи:** метод
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[Step#Определение|Step]] — метод [[ISimClock#Определение|ISimClock]]. Вызов увеличивает [[TickIndex#Определение|TickIndex]] на единицу. Цикл копит время кадра и вызывает метод, пока запас покрывает один шаг. Предел числа вызовов за один кадр источники не задают.

## Принимаемые типы данных

| Параметр | Тип | Описание |
| --- | --- | --- |
| `fixedDt` | `float` | Длительность шага в секундах. В срезе равна 1/30 |
| **Возвращает** | нет | Метод значение не возвращает |
