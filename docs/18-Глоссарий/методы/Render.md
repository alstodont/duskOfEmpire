# Render

## Определение

> [!abstract] Определение
> За один вызов рисует кадр по уже посчитанному состоянию. Авторитетный мир не меняет.

^glossary-def

**Тип записи:** метод
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[Render#Определение|Render]] — единственный метод [[IRenderSystem#Определение|IRenderSystem]]. В Phase 0 этим методом на экран попадает куб. Поля контекста кадра источники не задают. Вызов может случаться чаще, чем [[Step#Определение|Step]].

## Принимаемые типы данных

| Параметр | Тип | Описание |
| --- | --- | --- |
| `ctx` | контекст кадра | Уже посчитанное состояние и параметры кадра. Состав полей источники не задают |
| **Возвращает** | нет | Метод значение не возвращает |
