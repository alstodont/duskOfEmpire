# ISimClock

## Определение

> [!abstract] Определение
> Контракт часов симуляции хоста. Контракт открывает частоту шага, номер шага и метод одного шага.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[ISimClock#Определение|ISimClock]] живёт на хосте. Частоту открывает [[TickRate#Определение|TickRate]]. Номер шага открывает [[TickIndex#Определение|TickIndex]]. Один шаг выполняет [[Step#Определение|Step]]. В Phase 0 те же часы стоят в цикле клиента, потому что сетевого хоста ещё нет. Контракт от этого не становится клиентским авторитетом: мир по-прежнему считает сторона хоста.
