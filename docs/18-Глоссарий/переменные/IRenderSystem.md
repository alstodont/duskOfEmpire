# IRenderSystem

## Определение

> [!abstract] Определение
> Контракт системы отрисовки. У контракта один метод кадра. Метод кадра авторитетный мир не меняет.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0

## Смысл

[[IRenderSystem#Определение|IRenderSystem]] реализует [[Render#Определение|Render]]. Кадр читает уже посчитанное состояние. Система этого контракта в ECS хоста записи не делает.
