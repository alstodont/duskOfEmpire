# lightRT

## Определение

> [!abstract] Определение
> Цель рендера света. Phase 0 создаёт цель как заглушку и на расчёт симуляции свет не подаёт.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[lightRT#Определение|lightRT]] стоит в конвейере с Phase 0 вместе с заглушкой `light.fx`. Свет относится к виду клиента. В Phase 0 выборка из цели не меняет состояние, которое считает [[Update#Определение|Update]]. Геймплейное влияние света на механику движок наращивает после Phase 0.
