# GroundCleanupSec

## Определение

> [!abstract] Определение
> Период удаления лута, который лежит на земле, в секундах. Значение по умолчанию равно 300.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[GroundCleanupSec#Определение|GroundCleanupSec]] лежит в секции [[GameConfig#^glossary-def-Loot|Loot]] снимка [[GameConfig#Определение|GameConfig]]. Хост убирает наземный лут по этому периоду. 300 секунд соответствуют очистке раз в 5 минут.

## Принимаемые типы данных

| Аспект | Значение |
| --- | --- |
| Тип | `float` |
| Диапазон | Значение по умолчанию 300. Иной допустимый диапазон источники не задают |
| Единица | секунда |
| Обязательность | Обязательно в секции лута |
| Пустое значение | Не допускается. При отсутствии поля в файле действует 300 |
