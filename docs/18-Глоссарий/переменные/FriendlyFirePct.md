# FriendlyFirePct

## Определение

> [!abstract] Определение
> Доля урона по союзнику в процентах от обычного урона. Значение по умолчанию равно 10.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[FriendlyFirePct#Определение|FriendlyFirePct]] лежит в [[GameConfig#Определение|GameConfig]] и входит в правила матча. Хост отдаёт его клиентам через [[IMatchConfig#Определение|IMatchConfig]]. Локальная перезагрузка [[IClientPrefs#Определение|IClientPrefs]] это значение в матче не меняет.

## Принимаемые типы данных

| Аспект | Значение |
| --- | --- |
| Тип | `int` |
| Диапазон | Значение по умолчанию 10. Иной допустимый диапазон источники не задают |
| Единица | процент обычного урона |
| Обязательность | Обязательно в снимке конфигурации |
| Пустое значение | Не допускается. При отсутствии поля в файле действует 10 |
