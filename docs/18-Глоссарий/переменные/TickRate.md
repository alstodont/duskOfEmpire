# TickRate

## Определение

> [!abstract] Определение
> Частота фиксированного шага симуляции на хосте. В срезе равна 30 шагам в секунду.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[TickRate#Определение|TickRate]] принадлежит [[ISimClock#Определение|ISimClock]]. Один шаг, который выполняет [[Step#Определение|Step]], длится 1/[[TickRate#Определение|TickRate]] секунды. В срезе это 1/30 секунды.

## Принимаемые типы данных

| Аспект | Значение |
| --- | --- |
| Тип | `float` |
| Диапазон | В срезе значение равно 30 |
| Единица | шаг/с |
| Обязательность | Обязательно у часов хоста |
| Пустое значение | Не допускается |
