# IMatchConfig

## Определение

> [!abstract] Определение
> Контракт правил матча. Экземпляр задаёт хост. Клиент в матче читает экземпляр и локально его не заменяет.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[IMatchConfig#Определение|IMatchConfig]] покрывает память, урон, урон по союзнику, орды, таймеры лута и скиллы. Числа Phase 0 берёт из [[GameConfig#Определение|GameConfig]]. В Phase 0 сети может не быть: тип в коде уже отделён от [[IClientPrefs#Определение|IClientPrefs]]. Имена членов контракта, кроме чисел из [[12-Журнал-решений#DR-008]], источники не задают.

## Принимаемые типы данных

| Аспект | Значение |
| --- | --- |
| Тип | контракт C# |
| Кто пишет | Хост |
| Кто читает в матче | Клиент, без локальной замены |
| Обязательность | Тип обязателен с Phase 0. Сетевая рассылка обязательна с фазы 10 |
| Пустое значение | Не допускается |
