# IClientPrefs

## Определение

> [!abstract] Определение
> Контракт настроек этой машины клиента. Локальная перезагрузка в матче допустима и правила матча не меняет.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[IClientPrefs#Определение|IClientPrefs]] хранит громкость, чувствительность мыши, яркость и качество постэффектов. Имена полей источники не задают. Кнопка ImGui в Phase 0 перезагружает этот контракт. Перезагрузка не меняет [[IMatchConfig#Определение|IMatchConfig]].

## Принимаемые типы данных

| Аспект | Значение |
| --- | --- |
| Тип | контракт C# |
| Категории | Громкость, чувствительность мыши, яркость, качество постэффектов |
| Имена полей | Источники не задают |
| Обязательность | Тип обязателен с Phase 0 |
| Пустое значение | Не допускается |
