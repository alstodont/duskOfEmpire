## Смысл

[[memoryViewRT#Определение|memoryViewRT]] принимает вид после фильтра памяти. Phase 0 создаёт цель и заглушку `memory.fx`. Какие цели шейдер читает, источники не задают. Фаза 3 включает фильтр. До фазы 3 содержимое цели на геймплей не влияет.
