# TickIndex

## Определение

> [!abstract] Определение
> Целый номер шага симуляции. Каждый выполненный шаг увеличивает номер на единицу.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[TickIndex#Определение|TickIndex]] принадлежит [[ISimClock#Определение|ISimClock]]. Номер растёт на единицу в конце каждого [[Step#Определение|Step]]. Начальное значение источники не задают.

## Принимаемые типы данных

| Аспект | Значение |
| --- | --- |
| Тип | `int` |
| Диапазон | Целое. Шаг изменения равен 1. Нижняя граница не задана |
| Единица | номер шага |
| Обязательность | Обязательно у часов хоста |
| Пустое значение | Не допускается |
