# TopLootWindowSec

## Определение

> [!abstract] Определение
> Длина окна в конце сессии, в котором сильный лут имеет наибольший шанс, в секундах. Значение по умолчанию равно 600.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[TopLootWindowSec#Определение|TopLootWindowSec]] лежит в секции [[GameConfig#^glossary-def-Loot|Loot]] снимка [[GameConfig#Определение|GameConfig]]. Хост применяет окно к уже зафиксированному пулу лута. 600 секунд соответствуют последним 10 минутам сессии.

## Принимаемые типы данных

| Аспект | Значение |
| --- | --- |
| Тип | `float` |
| Диапазон | Значение по умолчанию 600. Иной допустимый диапазон источники не задают |
| Единица | секунда |
| Обязательность | Обязательно в секции лута |
| Пустое значение | Не допускается. При отсутствии поля в файле действует 600 |
