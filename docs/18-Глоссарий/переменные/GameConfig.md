# GameConfig

## Определение

> [!abstract] Определение
> Снимок config.json в памяти после загрузки Phase 0.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0
**Дата:** 2026-11-15

## Смысл

[[GameConfig#Определение|GameConfig]] заполняется из `config.json`. Хост читает снимок и отдаёт правила матча через [[IMatchConfig#Определение|IMatchConfig]]. Скаляры снимка: [[FriendlyFirePct#Определение|FriendlyFirePct]] и [[RespawnPvpveSec#Определение|RespawnPvpveSec]]. Таймеры лута лежат в секции [[GameConfig#^glossary-def-Loot|Loot]].

## Принимаемые типы данных

| Аспект | Значение |
| --- | --- |
| Тип | объект C# |
| Источник | `config.json` через System.Text.Json |
| Обязательность | Обязателен после загрузки Phase 0 |
| Пустое значение | Не допускается |

## Поля

> [!note] Memory
> Секция снимка с константами памяти. Имена полей внутри секции Phase 0 не задаёт.

^glossary-def-Memory

Границы стадий в секундах задаёт [[CONCEPT#4. Восприятие и память (LOCKED)]]: 0–15, 15–30, 30–45, 45–55, 55–60. Модификатор класса ±20 секунд.

> [!note] Pvpve
> Секция снимка с правилами режима PvPvE. Имена полей внутри секции Phase 0 не задаёт.

^glossary-def-Pvpve

> [!note] Womb
> Секция снимка с константами Роженицы. Имена полей внутри секции Phase 0 не задаёт.

^glossary-def-Womb

> [!note] Herder
> Секция снимка с константами Загонщика. Имена полей внутри секции Phase 0 не задаёт.

^glossary-def-Herder

> [!note] Item
> Секция снимка с параметрами предмета. Имена полей внутри секции Phase 0 не задаёт.

^glossary-def-Item

> [!note] Slots
> Секция снимка с параметрами слотов экипировки. Имена полей внутри секции Phase 0 не задаёт.

^glossary-def-Slots

> [!note] Loot
> Секция снимка с таймерами лута. Содержит период очистки земли, окно сильного лута и период расходника стрелка.

^glossary-def-Loot

Секция содержит [[GroundCleanupSec#Определение|GroundCleanupSec]], [[TopLootWindowSec#Определение|TopLootWindowSec]] и [[ShooterConsumableCooldownSec#Определение|ShooterConsumableCooldownSec]].
