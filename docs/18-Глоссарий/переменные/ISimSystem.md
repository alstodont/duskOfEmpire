# ISimSystem

> [!abstract] Определение
> Контракт системы симуляции. У контракта один метод шага мира и нет метода кадра.

^glossary-def

**Тип записи:** переменная
**Версия:** 1.0

## Смысл

[[ISimSystem#Определение|ISimSystem]] реализует [[Update#Определение|Update]]. Проект `DuskOfEmpire.Sim` собирает такие системы. Система этого контракта на `DuskOfEmpire.Rendering` не ссылается.
